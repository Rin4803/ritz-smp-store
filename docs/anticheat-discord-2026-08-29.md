# รายงานการเชื่อม Anti-Cheat เข้า Discord

วันที่ตรวจสอบ: 29 สิงหาคม 2026

## ขอบเขต

ตรวจสอบปลั๊กอิน Anti-Cheat ที่ติดตั้งจริงบนเซิร์ฟเวอร์ พบว่าใช้ `GrimAC` รุ่น `2.3.74-9e26fd9` และมีไฟล์กำหนดค่า Discord ที่ `/plugins/GrimAC/discord.yml` โดย GrimAC รองรับการแจ้งเตือนผ่าน Discord Webhook โดยตรง

## การตั้งค่าที่ดำเนินการ

เปิดใช้งานการส่งแจ้งเตือน Discord ใน GrimAC และกำหนด Webhook ที่ผู้ใช้ส่งให้เป็นปลายทาง โดยไม่บันทึก URL หรือ token ของ Webhook ลงในเอกสาร, Git และข้อความรายงาน

ปลายทางได้รับการตรวจด้วยการอ่านข้อมูล Webhook แบบไม่ส่งข้อความ และยืนยันว่า `channel_id` คือ `1542991929548214392` ภายใน guild เดียวกับระบบ Discord ของเซิร์ฟเวอร์

## การตรวจหลังโหลดระบบ

รีสตาร์ทเซิร์ฟเวอร์เพื่อให้ GrimAC โหลด configuration ใหม่ แล้วตรวจ startup log พบว่า GrimAC ถูกโหลด และไม่พบข้อความว่า webhook ถูกปฏิเสธหรือปลั๊กอินถูก disable จากการตั้งค่านี้ ข้อความ SLF4J ที่พบเป็นคำเตือน logger provider ของ GrimAC ไม่ใช่ข้อผิดพลาดการเชื่อม Webhook

## ข้อจำกัดการยืนยัน

ยังไม่ได้สร้างเหตุการณ์โกงจริงเพื่อทดสอบการแจ้งเตือน เพราะไม่ควรสร้างข้อมูลหรือพฤติกรรมโกงในเซิร์ฟเวอร์จริง การยืนยันระดับข้อความแจ้งเตือนควรทำเมื่อมีผู้เล่นจริงถูก GrimAC ตรวจพบ หรือใช้ staging server ที่แยกจากผู้เล่นจริง

## การดูแลความลับ

Webhook URL ถือเป็น credential หาก URL นี้ถูกเผยแพร่ในที่สาธารณะควรลบ Webhook เดิมแล้วสร้างใหม่ทันที จากนี้เอกสารและ GitHub จะอ้างอิงเฉพาะ channel ID และจะไม่เก็บ token ของ Webhook
