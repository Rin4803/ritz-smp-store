# ขอบเขตเว็บร้านค้าสำหรับผู้เล่น RitzSMP

อัปเดตล่าสุด: 28 กันยายน 2026

## ขอบเขต public ที่เปิดให้ผู้เล่นใช้

หน้าเว็บหลักของ RitzSMP ถูกกำหนดให้เน้นเฉพาะงานร้านค้า:

- ดูรายการยศและสิทธิประโยชน์
- เข้าสู่ระบบผู้เล่น
- เติมเงินเข้า Wallet พร้อมแนบสลิป
- ดูยอดเงินคงเหลือ
- ซื้อยศด้วยยอดเงินใน Wallet
- ระบุชื่อ Minecraft สำหรับรับยศ
- ดูประวัติการซื้อและสถานะออเดอร์
- ดูประวัติธุรกรรม Wallet
- เปิดดูสลิปของรายการของตนเอง

## สิ่งที่ไม่แสดงในเมนู public

- สถานะเซิร์ฟเวอร์และข้อมูล technical ของ Minecraft
- หน้าเลือกเซิร์ฟเวอร์
- Admin Dashboard
- Bot Dashboard
- การตั้งค่า Discord หรือ RCON

การซ่อนลิงก์เป็นเพียงการปรับประสบการณ์หน้า public เท่านั้น การอนุญาตจริงยังคงตรวจที่ procedure ฝั่ง server ด้วย `protectedProcedure`, `adminProcedure` และ `ownerProcedure` ตามสิทธิ์ของผู้ใช้

## ระบบที่ยังคงแยกออกจากเว็บผู้เล่น

- Minecraft server และ DiscordSRV ยังคงทำงานบน MCSV
- RitzSMP AI และ Music bot ไม่ได้ถูกเปิดจากหน้า public
- Token, RCON password และ secret ต่าง ๆ ไม่ถูกเก็บใน source code
- ฐานข้อมูล MySQL/MariaDB และ ledger Wallet เดิมยังคงใช้ schema เดิม เพื่อลดความเสี่ยงต่อยอดเงินและประวัติธุรกรรม

## ผลการตรวจสอบรอบนี้

- TypeScript check: ผ่าน
- Vitest: ผ่าน 202 tests, ข้าม 3 tests ที่ต้องใช้ live secret/บริการภายนอก
- Production build: ผ่าน
- `git diff --check`: ผ่าน
- เพิ่ม `/healthz` และ bind server ที่ `0.0.0.0` สำหรับการย้ายโฮสต์
- เว็บไซต์เดิมยังไม่ถูกปิดจนกว่าจะมีโฮสต์ใหม่และทดสอบ flow ซื้อ/เติมเงินจริงแบบควบคุมแล้ว

## ขั้นตอนก่อนเปิดใช้งานโฮสต์ใหม่

1. ยืนยัน Firebase/Cloud Run project หรือ VPS ที่จะใช้
2. ตั้งค่า secrets ผ่าน secret manager ของผู้ให้บริการเท่านั้น
3. เชื่อมฐานข้อมูลเดิมหรือ restore จาก backup ไปฐานข้อมูลใหม่
4. ทดสอบ Login, เติมเงิน, การตรวจสลิป, Wallet และซื้อยศด้วยรายการทดสอบ
5. ตรวจสิทธิ์ว่าผู้เล่นเห็นเฉพาะข้อมูลของตนเอง
6. เปลี่ยน domain หลังผ่านการทดสอบและมี rollback สำรอง
